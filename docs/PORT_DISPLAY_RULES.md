# Port display rules

These rules affect presentation only. Stored and API port names must remain unchanged.

| Original name | Primary name | Characters | Recommended compact/mobile display |
| --- | --- | ---: | --- |
| Dalian Changxingdao Hengli Petrochemical Terminal | Dalian Changxingdao Hengli Petrochemical Terminal | 49 | `Dalian Changxingdao Hengli…` with tap/focus access to the full name |
| Chittagong (Chattogram) | Chittagong | 10 | `Chittagong` |

## Rules

1. The primary display name is the text before a trailing parenthesized alternate name.
2. Preserve enough leading words to identify the port; truncate only at the available field boundary with an ellipsis.
3. Size compact port fields against the 49-character reference, while allowing horizontal scrolling in dense tables.
4. The full original name must be available by keyboard focus and touch interaction, not only by hover.
5. Search results may wrap to show the full original name. Never rewrite the underlying port record.
